- [x] Starter interface and project structure
- [ ] Review and approve the moral floor
- [ ] Define privacy, safety, and room rules

- [ ] Accounts and sign-in

- [ ] Reporting, blocking, and moderation tools

- [ ] Show when a message is from Bryar versus a person

- [ ] WebRTC signaling

- [ ] Camera/microphone controls and permission handling

- [ ] Decide ad format and provider

- [ ] Add privacy disclosures and consent controls as required

## Stage 6: Release
- [ ] Test on Android devices
- [ ] Publish privacy policy and terms

- [ ] Review store requirements and security
